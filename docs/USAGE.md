# 使用手册

这份文档只讲怎么操作。安装、签名、公网隧道配置看 [INSTALL.md](INSTALL.md)；报错看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 1. 连接电脑

1. 电脑上启动桥：

   ```bash
   node host/dsh-native-host.mjs --port 3090
   ```

   窗口别关。

2. 手机和电脑连同一个 Wi-Fi。
3. 打开 app，在「配对地址」里填桥打印的地址：

   ```text
   ws://192.168.1.10:3090/ws?token=<token>
   ```

   也可以点「扫码连接」，扫电脑上的二维码页。

4. 点「连接」。
5. 看到会话列表就表示连上了。

第一次连成功后，地址会自动保存。下次打开 app 会直接重连，不用再填。

## 2. 界面怎么看

### 连接页

| 位置 | 作用 |
| --- | --- |
| 配对地址 | 填 `ws://` 或 `wss://` 地址 |
| 连接 | 发起连接 |
| 扫码连接 | 调起扫码，扫电脑二维码页 |
| 最近连接 | 点一条重新连接；「删除」只删记录 |
| 状态行 | 显示连接进度或错误 |

底部「设置」里可以关掉「自动连接」。

### 会话页

| 位置 | 作用 |
| --- | --- |
| 文件夹标题带 | 显示电脑端的会话分组；点一下折叠/展开 |
| 橙色数字 | 这个文件夹里的会话数 |
| 显示隐藏（N） | 显示/收起电脑端隐藏的会话 |
| 搜索框 | 按标题和工作目录过滤 |
| 刷新 | 重新拉会话、标题、文件夹和隐藏状态 |
| + | 新建会话 |

### 聊天页

| 位置 | 作用 |
| --- | --- |
| 顶部标题 | 当前会话名，跟电脑端一致 |
| 标题下的灰字 | 工作目录 |
| 模型 | 选择模型/配置 |
| … | 刷新、新建、切模型、设置、复制整段对话、断开 |
| 消息右下角 | 复制 / 编辑（用户消息）/ 引用（助手消息） |
| 底部输入框 | 输入问题 |
| 发送 / 停止 | 发送；回复中变成停止 |

## 3. 找会话

- 会话按电脑端的文件夹分组。点文件夹标题带可以收起或展开。
- 想看的会话被隐藏了，点顶部的「显示隐藏（N）」。隐藏会话会出现在原来的文件夹里，并标「已隐藏」。
- 再点「隐藏已隐藏」就收起来。
- **长按**一个会话可以隐藏它；再长按可以取消隐藏。这个改动会同步到电脑端。
- 电脑端改了隐藏状态或文件夹，手机点「刷新」。
- 搜索时先决定要不要显示隐藏，否则隐藏会话搜不到。

## 4. 打开和阅读

1. 点一条会话。
2. app 先显示最近 10 条消息。
3. 想看更早的，在消息列表上**往下拉**（手指从上往下滑）。每拉一次加载更早 10 条，最多到最近 200 条。
4. 打开时会自动停在最新一条。

如果顶部出现：

```text
会话没能恢复（...）。可以先看历史，或新建会话。
```

说明这个会话在电脑端暂时接不上。历史还能看，但不能发消息。点「刷新」重开，或新建会话。

如果输入框显示「会话未就绪」，也是同一个原因；发送按钮会被禁用。

## 5. 发消息

1. 在底部输入框输入内容。
2. 点「发送」。
3. 回复会边生成边显示；工具调用会显示成卡片。
4. 想中断，点「停止」。

回复完成后，标题会跟电脑端重新同步一次。

## 6. 复制、编辑、引用

- **复制**：复制这条消息的文字。代码块右上角也有自己的「复制」。
- **编辑**：只出现在你发的消息上。点它，内容会放回输入框，改完再发送。
- **引用**：只出现在助手回复上。点它，回复会以 `>` 引用形式插入输入框，你再补充问题。
- 「…」→「复制当前消息」会把整段对话复制出来。

## 7. 权限请求

电脑端要执行工具时，会弹出一个权限层：

```text
电脑上的 DSH 要执行一个工具。允许这一次？
```

下面列出 ACP 返回的选项，常见是允许一次、总是允许、拒绝。选「拒绝」会告诉电脑端不执行。

## 8. 换模型

1. 点聊天页右上角「模型」。
2. 在面板里选模型或配置项。
3. 选择会写回当前会话。

模型列表来自电脑端，手机不内置模型名。

## 9. 新建会话

1. 点会话页右上角「+」，或在聊天页「…」里点「新建会话」。
2. 填工作目录。默认是电脑端当前目录。
3. 点创建。

新会话标题先是「新会话」；电脑端生成正式标题后，手机在刷新或下次回复后同步。

## 10. 下次打开

- 上次连过的地址会自动重连。
- 上次打开的窗口会先从手机本地恢复，最近 10 条消息会一起显示；然后再后台连接电脑。
- 如果电脑端暂时连不上，窗口还能看，但不能发。
- 本地只保留最后一个窗口和最近 10 条消息，不是完整离线备份。

关掉「自动连接」后，下次启动会停在连接页，地址仍然保留。

## 11. 远程使用

1. 电脑上把桥绑到回环，并配置 TLS 隧道：

   ```bash
   node host/dsh-native-host.mjs --host 127.0.0.1 --port 3090 \
     --public-url https://your-tunnel.example.com
   ```

2. 手机填：

   ```text
   wss://your-tunnel.example.com/ws?token=<token>
   ```

3. 隧道进程要一直开着。免费隧道重启后域名可能变，手机改一次地址即可。

公网模式下，电脑上的控制页 `/` 也要带 `?key=<token>`；`/ws` 始终要 token。

### 换 token

```bash
rm ~/.dsh/dsh-pocket-token
node host/dsh-native-host.mjs --port 3090
```

Windows PowerShell：

```powershell
Remove-Item $HOME\.dsh\dsh-pocket-token
```

换完用新地址或新二维码，旧 token 立即失效。

## 12. 状态提示速查

| 看到什么 | 先做什么 |
| --- | --- |
| `401` | token 不对，重新看桥打印的地址 |
| `403` | IP 被封；10 次错误 token 封 1 小时，重启桥可清 |
| `WebSocket 错误 200` | 鸿蒙错误码；检查 Wi-Fi、隧道、地址 |
| `连不上` / 超时 | 同一 Wi-Fi？桥还在？先试局域网地址 |
| `unknown session` | 桥重启过；点刷新或新建会话 |
| `会话未就绪` | 会话没恢复；刷新/重开/新建 |
| 历史为空或提示 7-Zip | 电脑装 7-Zip，确保 `7z` 在 PATH |
| 文件夹/隐藏不一致 | 手机点「刷新」；电脑端刷新页面 |
| 重启没恢复窗口 | 之前是否成功打开过会话；缓存只有 10 条 |

## 13. 安全

桥的 token 可以让手机驱动电脑上的 DSH agent，agent 又能执行工具。把它当 SSH 私钥：

- 不要截图发人，不要提交到仓库；
- 远程必须用 TLS 隧道；
- 不用时关掉桥；
- 定期换 token；
- 不要把 `workspace.json`、会话日志或带 token 的截图发给别人。

更多见 [SECURITY.md](../SECURITY.md)。
