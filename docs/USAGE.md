# 使用说明

这份文档讲日常怎么用。第一次安装、签名和公网隧道配置看 [INSTALL.md](INSTALL.md)；报错排查看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 0. 最短路径

1. 电脑上启动桥：

   ```bash
   node host/dsh-native-host.mjs --port 3090
   ```

2. 手机和电脑连同一个 Wi-Fi。
3. 打开 app，在「配对地址」填入桥打印的地址，例如：

   ```text
   ws://192.168.1.10:3090/ws?token=<token>
   ```

   或点「扫码连接」，扫电脑上的二维码页面。
4. 连上后进入会话列表，点一个会话开始；没有就点「新建会话」。

第一次连成功后地址会自动保存，下次打开 app 直接重连。

## 1. 连接页

连接页有三块：

- **配对地址**：`ws://` 或 `wss://` 的完整地址，必须带 `/ws?token=...`。
- **连接**：发起连接；连接期间状态行会显示「正在加载会话…」。
- **最近连接**：点一条可以重新连接；右侧「删除」只删记录。
- **扫码连接**：调用系统扫码，扫电脑上桥的二维码页。

底部「设置」里只有「自动连接」开关。关掉后，下次启动不会自动连，但地址仍保留。

状态行会显示当前阶段：

```text
已连接，正在加载会话…
已连接 · 57 个会话
连不上：...
握手失败：...
WebSocket 错误 200
```

`WebSocket 错误 200` 是鸿蒙 WebSocket 的错误码，不是 HTTP 200；先检查手机 Wi-Fi 有没有 `inet` 地址，再看隧道。

## 2. 会话列表

### 文件夹

会话按电脑端 `~/.dsh/storages/workspace.json` 的 workspace 分组。每个文件夹是一条标题带：

- 左侧橙色竖条和加粗标题；
- 下面是文件夹路径；
- 右侧橙色数字是会话数；
- 点标题带可以折叠/展开。

### 显示隐藏

电脑端隐藏的会话默认不显示。顶部会显示：

```text
显示隐藏（13）
```

点一下，隐藏会话会出现在原来的文件夹里，并标「已隐藏」；再点「隐藏已隐藏」就收起来。

### 隐藏 / 取消隐藏

**长按**一个会话行，即可隐藏或取消隐藏：

- 隐藏后行会标「已隐藏」；
- 这个改动会写回电脑端 `workspace.json`；
- 电脑端 DSH 页面刷新后能看到；
- 电脑端改了隐藏状态，手机点「刷新」拉取。

这是刷新式同步，不是实时推送；两边同时写时以最后一次为准。

### 搜索

搜索框按标题和 cwd 过滤。搜索时「显示隐藏」的过滤仍然生效；想搜隐藏会话，先点「显示隐藏」。

### 刷新

会话页顶部的「刷新」会重新拉 `session/list`、标题、文件夹和隐藏状态。电脑端刚改过名字或隐藏状态时用这个。

## 3. 打开会话

点一条会话。app 会：

1. 请求最近 **10 条**历史；
2. 调用 `session/resume`；
3. 拉当前标题；
4. 滚到最新一条。

标题带下面的 cwd 是会话的工作目录。右上角：

- **模型**：打开模型/配置选择面板；
- **…**：更多操作（复制整段对话等）。

### 历史分页

首屏只有最近 10 条。**滑到顶部**时自动加载更早 10 条；加载后保持当前阅读位置，不会跳回顶部。最多回放最近 200 条。

如果只想看最新，打开后不用动；想往回翻就往下滑（手指从屏幕上方往下拉）。

### 标题同步

聊天窗口顶部、会话列表行和本地缓存三处使用电脑端标题。打开会话、刷新列表、每次回复结束后都会重新拉一次 `phone/titles`。

电脑端改名后：

- 手机下一次刷新或回复会更新；
- 旧窗口缓存里的标题也会被覆盖。

手机端不提供重命名入口；命名以电脑端为准。

### 会话未就绪

如果标题下方出现：

```text
会话没能恢复（...）。可以先看历史，或新建会话。
```

说明 `session/resume` 失败。此时：

- 历史仍可读；
- 输入框显示「会话未就绪」；
- 发送按钮被禁用。

处理：点「刷新」后重新打开，或「新建会话」。如果报 `unknown session`，通常是电脑端桥重启过，手机拿着旧 session ID；新建会话即可。

## 4. 聊天

### 发送

输入内容，点「发送」。回复会流式出现：

- 普通文本按 Markdown 渲染；
- 工具调用显示成卡片，状态 `running` / `done`；
- 推理内容单独折叠；
- 底部可能显示 usage。

输入框支持多行。回复过程中按钮变成「停止」，点它会发 `session/cancel`。

### 复制 / 编辑 / 引用

每条消息右下角有操作：

- **复制**：复制消息文本；代码块也有自己的「复制」。
- **编辑**：只对用户消息出现；把这条内容放回输入框，改完再发。
- **引用**：把助手回复的内容作为引用插入输入框，再补充你的问题。

「…」里的「复制当前消息」可以复制整段对话。

### 权限请求

电脑端 DSH 要执行工具时，app 会弹权限层：

```text
电脑上的 DSH 要执行一个工具。允许这一次？
```

选项由 ACP 返回，可能是「允许一次」「总是允许」「拒绝」等。选「拒绝」会回一个拒绝结果给电脑端。

### 工具卡片

工具卡片显示工具名、参数摘要、结果摘要和状态。卡片上的「复制」复制工具结果；参数/结果过长时默认折叠，点开查看。

### 模型

右上角「模型」打开配置面板，列出 ACP 返回的模型和配置项（例如 DeepSeek-V4.1-Flash）。选择后通过 `session/set_config_option` 写回会话。

模型列表来自电脑端；手机不硬编码模型名。

## 5. 新建会话

点会话页右上角「+」或欢迎页「新建会话」：

1. 填工作目录（默认取电脑端当前目录）；
2. 点创建；
3. 成功后进入新会话，标题为「新会话」，电脑端生成正式标题后手机在刷新/回复后同步。

工作目录必须存在；不存在时 DSH 会报错。

## 6. 上次窗口与自动连接

### 自动连接

第一次成功连上后，地址写入 Preferences。之后启动 app：

- 有保存地址且自动连接开着 → 直接连；
- 连不上 → 停在连接页，显示错误，地址还在；
- 关掉「自动连接」→ 不自动连。

### 窗口缓存

打开会话并读到历史后，app 会把**当前窗口 + 最近 10 条消息**写入本地缓存。重启 app：

- 约 5 秒内先显示上次窗口和消息，不用等网络；
- 然后后台连接、`session/resume`；
- 恢复失败就保持只读历史。

缓存只是最近 10 条，且单条长文本会截断；完整历史仍在电脑端。它记录的是**最后一个窗口**，不是多个标签页。

卸载 app 会清掉缓存和保存的地址。

## 7. 远程使用

### 启动方式

不要让桥直接暴露在公网。用带 TLS 的隧道，并把桥绑到回环：

```bash
node host/dsh-native-host.mjs --host 127.0.0.1 --port 3090 \
  --public-url https://your-tunnel.example.com
```

手机填：

```text
wss://your-tunnel.example.com/ws?token=<token>
```

### 注意

- 隧道进程要一直开着；免费隧道重启后域名可能变化。
- 域名变了，手机改一次地址；改完又会自动保存。
- 公网模式下，电脑上的控制页 `/` 也需要 `?key=<token>`；`/ws` 始终要 token。
- 不要用 `ws://` 直接映射公网；token 会明文传输。

### 换 token

```bash
rm ~/.dsh/dsh-pocket-token
node host/dsh-native-host.mjs --port 3090
```

然后用新地址/新二维码。旧 token 立即失效。

## 8. 常见问题速查

| 现象 | 先看 |
| --- | --- |
| `401` | token 不对；看 `~/.dsh/dsh-pocket-token` |
| `403` | IP 被封；10 次错误 token 封 1 小时，重启桥可清 |
| `WebSocket 错误 200` | 鸿蒙错误码；查 Wi-Fi `inet`、隧道、ngrok 跳过头 |
| `连不上` / 超时 | 同一 Wi-Fi？桥还在？端口对？先试局域网 |
| `unknown session` | 桥重启过；刷新或新建会话 |
| 历史为空 / 要 7-Zip | 安装 7-Zip，确保 `7z` 在 PATH |
| `会话未就绪` | resume 失败；刷新/重开/新建 |
| 文件夹/隐藏不同步 | 点「刷新」；看 `workspace.json` 和备份 |
| 重启没恢复窗口 | 之前是否成功打开过会话；缓存只有 10 条 |
| 扫码页打不开 | 公网模式要 `?key=`；局域网直接 `/` |

## 9. 安全

桥的 token 可以让手机驱动电脑上的 DSH agent，而 agent 能执行工具。把它当 SSH 私钥：

- 不要截图/发群/提交到仓库；
- 远程必须用 TLS 隧道；
- 不用时关掉桥；
- 定期换 token；
- 不要把 `workspace.json`、session 日志或带 token 的截图发给别人。

更多见 [SECURITY.md](../SECURITY.md)。

## 10. 已知限制

- 只支持 ACP 暴露的能力；图片/附件、终端、文件树、预览、计划视图没有。
- 历史最多 200 条，每次 10 条。
- 窗口缓存 10 条，单条截断。
- 文件夹/隐藏是刷新式同步，不是实时。
- 大日志首次打开仍要在电脑端解压，可能慢。
- 手机端不提供会话重命名；标题以电脑端为准。
